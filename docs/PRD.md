# 사이트 설계도(PRD) — 새싹 공방

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
주말 데이트 커플이 함께 테라리움·미니 화분을 만들어 가져가는 원데이 클래스 공방.

## 2. 손님
- 누가: 주말 데이트 커플
- 어디서 알고 오나: 인스타그램 (프로필 링크 → 사이트 첫 화면)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격
2. 날짜·시간
3. 무엇을 만드나 (테라리움·미니 화분)
4. 초보도 가능한지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 작품·수업 사진: 지금은 **예시 사진(가상)**으로 자리를 채운다. 사진마다 "예시 이미지"라고 작게 표시하고, 실제 사진이 생기면 바로 바꾼다.
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 수업 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + [수업 문의하기] 버튼 + 테라리움 예시 사진
2. 무엇을 만드나요 — 테라리움·미니 화분 소개, 완성품은 가져가요 (예시 사진)
3. 이런 분께 좋아요 — 커플 데이트, 처음 해 보는 분도 OK (초보 가능 안내)
4. 가격·시간 안내 — (미정) 칸, 확정되면 채움
5. 후기 자리 (비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 희망 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제·온라인 예약 확정
- 사진 올리기
- 알림 메일
- 블로그

## 10. 첫 화면 한 문장 후보
1. 이번 주말, 둘이 함께 작은 숲을 만들어요.
2. 손재주 없어도 괜찮아요. 둘이 만드는 나만의 테라리움.
3. 데이트 끝에 들고 가는 초록 선물, 새싹 공방 원데이 클래스.

## 11. 다음에 할 것
- 예시 사진을 실제 작품·수업 사진으로 교체
- 실제 후기가 생기면 후기 자리에 넣기
- 가격·시간·위치·연락 방법 확정해서 채우기
- 회원가입·로그인 (필요해지면, 개인정보 처리방침 함께)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (9번이 '예'일 때) 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
